# Промт для переноса проекта HMSTR.FM в другой чат / другую ИИ

Скопируй всё ниже и вставь в новый чат. Приложи `index.html` (и `og.png`).

---

Ты помогаешь мне развивать сайт **HMSTR.FM**. Отвечай по-русски, коротко и по делу.

## Контекст
Моя подруга проводит радио-стримы на **Twitch**: зрители присылают в чат ссылку (YouTube, Spotify и др.) или название трека, она слушает, ставит оценку и иногда добавляет трек в плейлист. Сайт нужен, чтобы ей было удобно это делать. Первый стрим на сайте будет на следующем эфире.

## Текущее состояние
- Сайт: https://hmstrfm.vercel.app/ (GitHub → Vercel). Название везде **HMSTR.FM**. Файлы в репозитории: `index.html` (панель ведущей), `overlay.html` (оверлей для OBS), `og.png` (баннер превью ссылки 1200×630). Чистый HTML/CSS/JS, без сборки, без сервера.
- Панель: заявка вручную → очередь (▶ играть сейчас, ✕) → плеер → оценка 1–10 с подписью и эффектами на 9–10 → заметка → «В плейлист» / «Пропустить» / «Следующий». История, статистика, индикатор ON AIR, горячие клавиши (N, Пробел, 1–9/0, P, S, O, ↑/↓, M, T).
- Плеер: YouTube IFrame API (название и автор через `getVideoData`, подсветка по обложке), Spotify и SoundCloud встраиваются iframe, остальное — винил и кнопка «Открыть». Громкость 50% по умолчанию (`hmstr_vol`), только для YouTube.
- Шестерёнка ⚙️ → настройки: выбор из 10 тем с уникальными анимированными фонами (hamster, neon, space, lagoon, sakura, matrix, retro, volcano, platinum, stage), переключатели анимаций, Twitch-бот, OBS-оверлей, плейлист, экспорт/импорт JSON.
- Копирование плейлиста: «Исполнитель – Название», с очисткой «Official Video / Lyrics / HD…» (`cleanTitle`, `plName`); в настройках можно переключить на ссылки.
- Twitch-бот: браузер подключается к `wss://irc-ws.chat.twitch.tv` анонимно (`justinfan…`, только чтение), реагирует на команды (по умолчанию `!заказ, !sr, !order`), лимит заявок на зрителя в очереди, пауза между заявками, защита от дублей. Настройки в `hmstr_cfg`. Работает, пока панель открыта.
- Оверлей `overlay.html` читает `localStorage` (`hmstr_fm_v1`, `hmstr_theme`) через событие `storage` и опрос раз в секунду. Параметры: `?bg=green`, `?q=0` (скрыть очередь), `?logo=0`. Анимации: выезд карточки, вращающийся винил, эквалайзер, штамп оценки с кольцом, пульсация и конфетти на 9–10, список «Далее в эфире».
- Данные: `{queue:[], current:null, history:[]}`; поля элементов: `id,text,nick,comment,rating,note,pl,title,author,name,skipped,src`.

- Добавлено (v6): `sfx.js` (синтез звуков: джингл, аплодисменты на 9, эйрхорн на 10; играют в панели или в оверлее), слепое прослушивание (`cfg.blind`, клавиша B), таймер трека, окно «🏆 Итоги» (хит-парад, «любимчики», PNG 1080×1920 для сторис, экспорт плейлиста: поиск в Яндекс Музыке/Spotify, CSV), чёрный список ников/слов и очередь «На проверке» (`S.pending`), дедупликация по нормализованной ссылке, oEmbed-название и обложка для Spotify/SoundCloud (`title,author,thumb`), синхронизация нескольких вкладок через `storage`. Новое поле данных: `pending:[]`, у текущего трека `t0`.
- Решено не делать: публичную страницу для зрителей.

- Оверлей: аура из цветов обложки (доминирующий оттенок через canvas; при CORS-запрете остаются цвета темы), канвас-визуализатор (имитация, ритм от id трека, на паузе затихает), полоска прогресса (`pos`, `dur`, `t`, у не-YouTube таймер от `t0`), плашка «ЧАТ 7.8 · N» (`vote`), вспышка и дождь 🐹 на 10, 💀 и фейл на 1, сцены «Перерыв»/«Скоро начнём» с таймером и очередью (`brk`, `ev`), тикер оценок внизу (`hist`). Параметры: `?tick=0` без тикера, `?scene=0` без сцен.

## Не проверено на практике
Всё v9 написано без запуска в браузере: цвета из обложки (зависит от CORS у i.ytimg.com), `watch_videos`, светлые темы (фоны упрощены), сцены в OBS. Не сделано: альтернативные раскладки сторис («постер», «минимал»), просмотр архива по календарным месяцам и список эфиров.

## Ограничения и выводы
- Оверлей и панель общаются через общий `localStorage`, поэтому работают только в одном профиле браузера. В OBS: панель как Custom Browser Dock + оверлей как Browser Source (не проверено на практике). Запасной вариант: `overlay.html?bg=green` в окне браузера + Window Capture + Chroma Key.
- Бот читает чат, но не отвечает (для ответов нужен OAuth-токен и сервер). Работает только при открытой панели.
- Громкостью Spotify/SoundCloud из страницы управлять нельзя. Название трека знаем только для YouTube.
- Очередь локальная (один браузер). Заявки с сайта от зрителей возможны только с сервером.

## План (по приоритету)
1. Серверная часть (Vercel functions + KV/Upstash или Supabase): общее состояние для панели, оверлея и бота, чтобы оверлей работал из любого браузера и не зависел от открытой вкладки.
2. Бот с ответами в чат (OAuth, `!очередь`, `!скип` для модераторов, «твой трек в очереди №N»).
3. Публичная страница для зрителей: форма заявки, очередь, лайки/голосование.
4. Автоматически подтягивать название и обложку для Spotify/SoundCloud/других ссылок.
5. Звуковые эффекты (аплодисменты, эйрхорн на 10), «слепое прослушивание», хит-парад вечера и итоговая картинка для сторис, экспорт плейлиста в Spotify/Яндекс Музыку.
